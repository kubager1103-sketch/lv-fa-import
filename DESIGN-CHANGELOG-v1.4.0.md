# LV-FA Import v1.4.0 – design changes

The public UI is aligned more closely with the real LV-FA Photo Center visual system.

- Header uses the same 1280px alignment and 116px desktop height as Photo Center.
- Language switch (CZ / EN) is permanently visible in the header.
- Admin link is permanently visible in the header as “Přihlášení”.
- Removed the body-level “LV-FA Import” eyebrow and descriptive lead; the body starts with “Odeslat fotografie”.
- Contact labels use “Jméno”, “E-mail”, and “Instagram”; no example placeholders are used.
- Upload wording uses the formal Czech form “Nahrát fotografie” / “vyberte… přetáhněte…”.
- Photo cards are compact, rounded, and visually closer to Photo Center cards.
- Desktop: two photo cards per row. Mobile: one photo card per row.
- Photo is shown on the left/top of its card and is visually smaller than the previous full-width row layout.
- Per-photo fixed metadata shows the already-entered name and optional Instagram as non-editable text.
- Per-photo editable fields are Airline / airport and Aircraft type.
- Footer text is “© Letecký vykřičník & FlyAlert - Import fotografií”.
- Existing backend behavior and Photo Center filename compatibility are retained.
