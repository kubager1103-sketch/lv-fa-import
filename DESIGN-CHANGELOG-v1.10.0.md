# LV-FA Import v1.10.0

- Instagram is explicitly marked optional in CZ/EN.
- Instagram entered by the photographer is automatically shown on each photo card with `@` prefix; the photographer does not need to repeat it per photo.
- Added bilingual field hints/placeholders for airline/airport and aircraft fields.
- Expanded airline autocomplete suggestions substantially.
- Added separate Czech airport names for CZ and English airport names for EN; airline names remain international.
- Expanded aircraft autocomplete suggestions, including Airbus A220 variants, A320neo/A321neo/LR/XLR, A330neo, A350 variants, Boeing 737 MAX family and many other types.
- Autocomplete suggestions are rebuilt when switching CZ/EN so airport language follows the selected interface language.
